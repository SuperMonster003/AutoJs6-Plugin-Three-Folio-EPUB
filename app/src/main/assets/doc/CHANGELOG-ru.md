# v1.0.0

###### 2026/09/19

* `Подсказка` Сборка для разработки: этапы дорожной карты P0 (каркас, проверка Readium, тестовые образцы) в работе; первый публичный выпуск выходит на этапе P8 дорожной карты
* `Функция` Основная кнопка `Читать EPUB` и действие в контекстном меню для файлов `.epub` в файловом менеджере AutoJs6 (ID плагина `readium-epub-reader`, Explorer Action v2); файлы с расширением `.epub`, которые хост сообщает как `application/zip`, тоже принимаются
* `Функция` База читалки: книги EPUB 2 и EPUB 3 отображаются навигатором Readium, с оглавлением и подтверждаемыми внешними ссылками
* `Функция` Память позиции чтения: последняя позиция каждой книги сохраняется под отпечатком содержимого (быстрый ключ при открытии, затем SHA-256 всего файла) и восстанавливается при следующем открытии; `Начать сначала` удаляет ее
* `Функция` Оформление читалки: название книги и текущая глава в панели инструментов, индикатор прогресса с синтетической позицией и процентом, полноэкранный режим по касанию центра, зоны касания и кнопки громкости для перелистывания, переключатель режима прокрутки
* `Функция` Панель настроек чтения: размер текста, шрифт, межстрочный интервал, поля страницы, интервал между абзацами, выравнивание, переносы, стили издателя, число колонок и постраничная или прокручиваемая разметка применяются сразу и запоминаются для всех книг; светлая, сепия и темная темы плюс `Как в хосте`, панель инструментов и системные панели перекрашиваются под тему
* `Функция` Книги читаются на месте через выданный файловый дескриптор с позиционными чтениями; ничего не копируется и не распаковывается в хранилище
* `Функция` Интерфейс, инструкции, README и changelog на 10 языках
* `Зависимость` Добавлен Readium Kotlin Toolkit 3.4.0 (`readium-shared`, `readium-streamer`, `readium-navigator`, `readium-navigator-media-tts`)
