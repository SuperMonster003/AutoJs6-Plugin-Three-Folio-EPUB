3-Folio EPUB는 AutoJs6의 EPUB 전자책 읽기 플러그인이며, 단독 리더로도 사용할 수 있습니다. EPUB 2와 EPUB 3 책을 열고 목차, 전체 텍스트 검색, 북마크, 하이라이트와 메모, 읽어 주기를 제공하며, 스크립트에서 책 내용을 읽거나 리더를 열 수도 있습니다.

### 시작하기

1. AutoJs6의 "플러그인 센터"에서 이 플러그인이 활성화되어 있는지 확인합니다.
2. AutoJs6 파일 관리자에서 EPUB 파일을 탭하면 책이 리더에서 열립니다. 해당 파일의 메뉴에서 "EPUB 읽기"를 선택할 수도 있습니다.
3. 페이지의 왼쪽이나 오른쪽을 탭하거나 볼륨 키를 눌러 페이지를 넘기고, 가운데를 탭해 도구 모음을 표시하거나 숨깁니다. 같은 책을 다시 열면 마지막 위치에서 이어집니다.
4. AutoJs6 없이 사용할 때는 홈 화면 아이콘으로 이 플러그인을 열고 "EPUB 열기"를 탭해 책을 선택합니다.

### 주요 기능

- **목차와 읽기 위치**: "목차"에서 원하는 장으로 이동합니다. 책마다 마지막 위치를 기억해 옮기거나 이름을 바꿔도 이어 읽을 수 있으며, "처음부터 읽기"로 위치를 지울 수 있습니다.
- **읽기 설정**: "읽기 설정"에서 글자 크기, 글꼴, 간격, 정렬, 페이지 넘김 방식을 조정하고 "라이트", "세피아", "다크", "호스트 따르기" 테마를 고를 수 있습니다. "글꼴 가져오기"로 TTF 또는 OTF 글꼴을 추가합니다.
- **세로쓰기와 고정 레이아웃**: 중국어와 일본어 세로쓰기 책은 세로로 표시되며, "글자 방향"에서 가로쓰기나 세로쓰기로 고정할 수 있습니다. 고정 레이아웃 책은 "펼침 보기"와 두 손가락 확대를 지원합니다.
- **검색과 북마크**: "검색"은 책 전체의 일치 항목을 앞뒤 문맥과 함께 보여 주고, 탭하면 해당 위치로 이동합니다. 도구 모음 아이콘으로 현재 페이지에 북마크를 추가하고 "북마크"에서 확인하거나 삭제합니다.
- **하이라이트와 메모**: 텍스트를 선택하고 "하이라이트" 또는 "메모 추가"를 고르며, 다섯 가지 색과 밑줄 스타일이 있습니다. "하이라이트와 메모"에서 이동하거나 편집할 수 있고, "내보내기"로 Markdown 파일에 저장할 수 있습니다.
- **읽어 주기**: "읽어 주기"는 시스템 음성 합성 엔진으로 현재 페이지부터 읽고, 읽는 문장을 강조하며 페이지를 자동으로 넘깁니다. 속도, 음성, "수면 타이머"를 설정할 수 있으며, "백그라운드에서 계속"을 켜면 리더를 닫아도 계속 읽습니다.
- **링크와 이미지**: 책 안의 링크는 원래 위치로 돌아갈 수 있고 각주는 팝업으로 표시됩니다. 외부 링크는 기본적으로 전체 주소를 먼저 보여 주고 확인한 뒤에만 브라우저로 넘깁니다. 이미지를 탭하면 전체 화면으로 볼 수 있습니다.
- **최근 책과 다른 앱**: 홈 화면 아이콘으로 최근 책 목록을 엽니다. 다른 앱에서 공유한 EPUB도 바로 열 수 있으며, "최근 책에 추가"로 목록에 남길 수 있습니다.
- **모양과 설정**: 언어, 야간 모드, "테마 색상"은 기본적으로 AutoJs6를 따릅니다. "설정"에서 페이지 넘김과 읽어 주기의 기본값을 정할 수 있으며, "업데이트 확인" 및 "릴리스 기록" 항목도 있습니다.

### 스크립트에서 사용하기

AutoJs6의 `epub` 모듈은 이 플러그인이 제공합니다. 리더를 열지 않고도 책의 메타데이터, 목차, 본문을 읽을 수 있습니다:

```js
let book = epub.open('./book.epub');
console.log(book.metadata.title, book.metadata.authors.join(', '));
book.toc.forEach(entry => console.log(entry.title));
console.log(book.text(0, { maxChars: 500 }));
book.close();
```

`epub.read()`는 이 플러그인의 리더를 열고 읽기 진행 상황을 스크립트에 알려 줍니다:

```js
let session = epub.read('./book.epub');
session.on('progress', e => console.log((e.totalProgression * 100).toFixed(1) + '%', e.chapterTitle || e.href));
session.on('error', e => console.warn(e.toString()));
session.on('close', e => console.log('closed:', e.reason));
```

- 경로는 절대 경로이거나 스크립트 작업 디렉터리 기준의 상대 경로여야 하며, `content://` 같은 URI는 받지 않습니다.
- 오류는 `epub.EpubError`로 발생하고 `code`가 원인을 나타냅니다. 예를 들어 플러그인이 비활성화되어 있으면 `PLUGIN_DISABLED`입니다. 먼저 `epub.isAvailable()`로 확인할 수 있습니다.
- 대부분의 메서드에는 Promise를 반환하는 Async 형태가 있습니다. 예를 들어 `epub.openAsync()`가 있습니다.
- 리더는 AutoJs6가 시작하므로 백그라운드에서 화면을 여는 데 대한 시스템 제한을 받습니다. `epub.read()`를 호출하는 스크립트는 AutoJs6 화면이 보일 때 실행하세요.

### 요구 사항

- Android 7.0 이상과 시스템 WebView.
- 파일 관리자에서 책을 열거나 `epub` 모듈을 사용하려면 AutoJs6 6.8.0 이상이 필요합니다. 홈 화면 아이콘으로 단독 사용할 때는 AutoJs6가 필요하지 않습니다.
- 읽어 주기에는 책 언어의 음성 데이터가 있는 음성 합성 엔진이 필요합니다.
- Android 13 이상에서는 읽어 주기 알림 컨트롤에 알림 권한이 필요하며, 거부해도 읽어 주기는 정상적으로 동작합니다.

### 자주 묻는 질문

**파일 관리자에 "EPUB 읽기"가 나타나지 않는 이유**

AutoJs6가 버전 요구 사항을 충족하고 이 플러그인이 "플러그인 센터"에서 활성화되어 있는지 확인합니다. 둘 다 충족되면 EPUB 파일에 "EPUB 읽기"가 나타납니다.

**지원하는 전자책 형식**

고정 레이아웃 책을 포함해 EPUB 2와 EPUB 3를 지원합니다. PDF, MOBI, AZW, CBZ와 오디오북은 지원하지 않으므로 Calibre 같은 도구로 먼저 EPUB로 변환하세요. DRM으로 보호된 책은 보호 안내를 표시하며 읽을 수 없습니다.

**읽어 주기에서 소리가 나지 않는 경우**

시스템 음성 합성 엔진에 책 언어의 음성 데이터가 있는지 확인하고 미디어 볼륨을 높이세요. 기기에 사용할 수 있는 엔진이 없으면 약 20초 후에 안내가 표시됩니다.

**이 플러그인이 네트워크를 사용하는 경우**

이 플러그인은 책이나 읽기 데이터를 업로드하지 않습니다. 책이 원격 리소스를 참조하거나 "업데이트 확인"을 탭할 때만 네트워크에 연결합니다. 책에는 스크립트가 들어 있을 수 있으니 신뢰할 수 있는 책만 여세요.

전체 스크립트 API는 [AutoJs6 문서](https://docs.autojs6.com/#/epub)를, 자세한 내용은 [프로젝트 페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Folio-EPUB)를 참고하세요.
