3-Folio EPUB は AutoJs6 向けの EPUB 電子書籍リーダープラグインで, 単体のリーダーとしても使えます. EPUB 2 と EPUB 3 の本を開き, 目次, 全文検索, ブックマーク, ハイライトとノート, 読み上げを備えています. スクリプトから本の内容を読み取ったり, リーダーを開いたりすることもできます.

### はじめに

1. AutoJs6 の "プラグインセンター" で本プラグインが有効になっていることを確認します.
2. AutoJs6 のファイルマネージャーで EPUB ファイルをタップすると, 本がリーダーで開きます. そのファイルのメニューから "EPUB を読む" を選ぶこともできます.
3. ページの左右をタップするか音量キーを押すとページがめくれ, 中央をタップするとツールバーの表示と非表示が切り替わります. 同じ本を再び開くと前回の位置から続きます.
4. AutoJs6 を使わない場合は, ホーム画面のアイコンから本プラグインを開き, "EPUB を開く" をタップして本を選びます.

### 主な機能

- **目次と読書位置**: "目次" から任意の章に移動できます. 本ごとに前回の位置を記憶し, 移動や名前の変更後も続きから読めます. "最初から読む" で位置を消去できます.
- **読書設定**: "読書設定" で文字サイズ, フォント, 間隔, 配置, ページ送りを調整し, "ライト", "セピア", "ダーク", "ホストに従う" から選べます. "フォントを取り込む" で TTF や OTF のフォントを追加できます.
- **縦書きと固定レイアウト**: 中国語と日本語の縦書きの本は縦書きで表示され, "文字方向" で横書きか縦書きに固定できます. 固定レイアウトの本は "見開き表示" とピンチズームに対応します.
- **検索とブックマーク**: "検索" は本の中の一致箇所を前後の文と共にすべて一覧し, タップでその位置に移動します. ツールバーのアイコンで現在のページにブックマークを付け, "ブックマーク" で確認と削除ができます.
- **ハイライトとノート**: テキストを選択して "ハイライト" または "ノートを追加" を選びます. 5 色と下線のスタイルがあり, "ハイライトとノート" で移動と編集, "エクスポート" で Markdown ファイルへの保存ができます.
- **読み上げ**: "読み上げ" はシステムの音声合成エンジンで現在のページから読み上げ, 読んでいる文をハイライトしてページを自動でめくります. 速度, 音声, "スリープタイマー" を設定でき, "バックグラウンドで続ける" をオンにするとリーダーを閉じても続きます.
- **リンクと画像**: 本の中のリンクは元の位置に戻ることができ, 脚注はポップアップで表示されます. 外部リンクは既定で完全なアドレスを先に表示し, 確認後にのみブラウザーへ渡します. 画像をタップすると全画面で表示されます.
- **最近の本と他のアプリ**: ホーム画面のアイコンから最近の本の一覧を開けます. 他のアプリから共有された EPUB も直接開け, "最近の本に追加" で一覧に残せます.
- **外観と設定**: 言語, ナイトモード, "テーマカラー" は既定で AutoJs6 に従います. "設定" ではページ送りと読み上げの既定値を設定でき, "更新を確認" と "リリース履歴" もあります.

### スクリプトでの使い方

AutoJs6 の `epub` モジュールは本プラグインが提供します. リーダーを開かずに本のメタデータ, 目次, 本文を読み取れます:

```js
let book = epub.open('./book.epub');
console.log(book.metadata.title, book.metadata.authors.join(', '));
book.toc.forEach(entry => console.log(entry.title));
console.log(book.text(0, { maxChars: 500 }));
book.close();
```

`epub.read()` は本プラグインのリーダーを開き, 読書の進み具合をスクリプトに通知します:

```js
let session = epub.read('./book.epub');
session.on('progress', e => console.log((e.totalProgression * 100).toFixed(1) + '%', e.chapterTitle || e.href));
session.on('error', e => console.warn(e.toString()));
session.on('close', e => console.log('closed:', e.reason));
```

- パスは絶対パスか, スクリプトの作業ディレクトリからの相対パスで指定します. `content://` などの URI は受け付けません.
- エラーは `epub.EpubError` として投げられ, `code` が原因を示します. 例えばプラグインが無効なときは `PLUGIN_DISABLED` です. 先に `epub.isAvailable()` で確認できます.
- 多くのメソッドに Promise を返す Async 版があります. 例えば `epub.openAsync()` です.
- リーダーは AutoJs6 が起動するため, バックグラウンドからの画面起動に関するシステムの制限を受けます. `epub.read()` を呼ぶスクリプトは AutoJs6 の画面が表示されている間に実行してください.

### 動作要件

- Android 7.0 以降と, システムの WebView.
- ファイルマネージャーから本を開く場合と `epub` モジュールには AutoJs6 6.8.0 以降が必要です. ホーム画面のアイコンから単体で使う場合は AutoJs6 は不要です.
- 読み上げには, 本の言語の音声データを備えた音声合成エンジンが必要です.
- Android 13 以降では, 読み上げの通知コントロールに通知の権限が必要です. 拒否しても読み上げは通常どおり使えます.

### よくある質問

**ファイルマネージャーに "EPUB を読む" が表示されない理由**

AutoJs6 がバージョン要件を満たし, 本プラグインが "プラグインセンター" で有効になっていることを確認します. 両方を満たすと, EPUB ファイルに "EPUB を読む" が表示されます.

**対応する電子書籍の形式**

固定レイアウトの本を含め, EPUB 2 と EPUB 3 に対応しています. PDF, MOBI, AZW, CBZ, オーディオブックには対応していないため, Calibre などのツールで先に EPUB に変換してください. DRM で保護された本は保護されている旨を表示し, 読むことはできません.

**読み上げの音が出ない場合の対処**

システムの音声合成エンジンに本の言語の音声データがあることを確認し, メディアの音量を上げます. 使えるエンジンが端末にない場合は, 約 20 秒後にメッセージが表示されます.

**本プラグインがネットワークを使う場合**

本プラグインが本や読書データをアップロードすることはありません. ネットワークを使うのは, 本がリモートのリソースを参照するときと, "更新を確認" をタップしたときだけです. 本にはスクリプトが含まれることがあるため, 信頼できる本だけを開いてください.

スクリプト API の全体は [AutoJs6 ドキュメント](https://docs.autojs6.com/#/epub) を, 詳しくは [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Folio-EPUB) をご覧ください.
