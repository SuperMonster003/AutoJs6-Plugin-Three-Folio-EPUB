# Test fixtures

All files in this directory are generated by `.python/generate_fixtures.py` from text written for
this repository (roadmap D22 / P0.3). They contain no third-party content and carry no license
other than the repository's MPL 2.0. `SHA256SUMS.txt` is written by the generator; verify with
`sha256sum -c SHA256SUMS.txt` from this directory. Regenerate after editing the generator and
commit the fixtures together with it.

The directory is also mounted as the `androidTest` assets source set (`app/build.gradle.kts`), so
instrumentation tests read these files by name.

| File | Purpose | Expected reader behavior |
| --- | --- | --- |
| `minimal-epub2.epub` | EPUB 2 with NCX, 3 chapters, one stylesheet | Opens; title `Minimal EPUB 2`; 3 reading-order items; NCX table of contents |
| `minimal-epub3.epub` | EPUB 3 with NAV, 3 chapters, internal link, footnote (`epub:type="noteref"`), 16x16 PNG image | Opens; title `Minimal EPUB 3`; nested NAV table of contents; footnote and anchor work |
| `malformed-not-a-zip.epub` | Plain text with an `.epub` name | Fails with a format error, no crash |
| `malformed-missing-container.epub` | ZIP without `META-INF/container.xml` | Fails, no crash |
| `malformed-missing-opf.epub` | `container.xml` points at a missing package document | Fails, no crash |
| `malformed-bad-ncx.epub` | EPUB 2 whose NCX is not well-formed XML | Opens or fails gracefully; must not crash (Readium tolerates a broken NCX) |
| `malformed-path-traversal.epub` | Manifest href `../../../etc/passwd` and a ZIP entry named `../escaped.txt` | Opens or fails gracefully; nothing is ever written outside the container |
| `malformed-many-entries.epub` | 2000 extra manifest and spine entries | Opens slowly but within limits; used for the P7 limit tests |
| `malformed-high-ratio.epub` | One 64 MiB zero-filled resource (deflates to a few KiB) | Opens; reading the blob must stay bounded (P7 resource limits) |
| `malformed-encrypted-lcp.epub` | `META-INF/encryption.xml` and `license.lcpl` declaring an LCP-protected chapter | Fails with a clear "protected" error (fallback content protection), never renders garbage |

Large performance samples (20 MB / 200 MB) are synthesized on demand by the P7 tools and are not
committed. Externally sourced samples (IDPF `epub3-samples`, W3C `epub-tests`) are not part of the
repository yet; when one is added it must be listed here with its source URL, license and SHA-256.
